# 💰 سیستم مدیریت مالی شخصی (Personal Finance Manager)

یک اپلیکیشن وب امن و کاربردی برای مدیریت هزینه‌ها، درآمدها، بودجه‌بندی ماهانه و تحلیل وضعیت مالی شخصی، توسعه‌یافته با فریم‌ورک قدرتمند **Flask** و پایگاه داده **SQLite**.

---

## ✨ ویژگی‌های کلیدی (Features)

- **🔐 احراز هویت امن:** سیستم کامل ثبت‌نام، ورود، مدیریت سشن‌ها، تغییر رمز عبور و نام کاربری با رمزنگاری استاندارد.
- **📊 مدیریت تراکنش‌ها:** قابلیت ثبت، ویرایش، حذف و فیلتر کردن تراکنش‌های درآمد و هزینه همراه با جزئیات کامل.
- **🎯 مدیریت بودجه ماهانه:** تعیین سقف بودجه برای دسته‌بندی‌های مختلف و رصد لحظه‌ای میزان پیشرفت و هزینه‌ها.
- **📈 داشبورد و نمودارهای تحلیلی:** نمایش گرافیکی وضعیت مالی، خلاصه‌ حساب‌ها و نمودارهای توزیع هزینه‌ها.
- **📤 خروجی گزارش‌ها:** امکان استخراج گزارش‌های مالی جهت بررسی‌های بیشتر.

---

## 🛠️ تکنولوژی‌های پشته (Tech Stack)

- **بک‌اند (Backend):** Python, Flask, Werkzeug, SQLite3
- **فرانت‌اند (Frontend):** HTML5, CSS3, Jinja2, JavaScript
- **پایگاه داده (Database):** SQLite با رعایت کامل محدودیت‌های کلید خارجی و یکپارچگی داده‌ها

---
